CoreOS

CoreOS is a little project built around Rust and Assembly.

It's still in active development. It's targeting BIOS — enabling CSM support and legacy boot would make the OS bootable on real hardware.

Story Behind It

CoreOS is an open source, free, and legit project.

It was built because of my ADHD and boredom. I am still a very young programmer.

Truth About It

This was never supposed to be a "mainstream OS," more of a "fun and giggles OS."

I'd like to keep building this OS. For more information about the project, feel free to email me :)
